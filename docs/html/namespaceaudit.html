◆ isValidSemanticVersion()

bool audit::isValidSemanticVersion ( const std::string & version)

Проверяет, соответствует ли строка формату семантической версии.

Допустимые форматы: "5", "1.2", "10.20.30". Запрещены: ведущие нули ("01.2"), буквенные суффиксы ("1.2-alpha"), префикс 'v'.

Parameters
versionСтрока для проверки.
Returns
true, если формат корректен; false в противном случае.
